## ✨ Ce que fait DZ Wedding

| Module | Ce qu'il gère |
|---|---|
| 📅 **Planning** | Calendrier mois / semaine / liste, créneaux déjeuner-dîner-journée, **blocage automatique des doubles réservations**, code couleur par statut |
| 👥 **Clients** | Fiche complète, réservataire (marié / mariée / famille), recherche instantanée par nom ou téléphone, historique |
| 💰 **Paiements** | Acompte → versements échelonnés → solde. Total / Payé / **Reste à payer** toujours visibles, reçus imprimables, alertes impayés |
| 📄 **Devis & Contrats** | Génération en un clic, montants **en toutes lettres (FR + AR)**, en-tête légal NIF / RC / AI / NIS, design festif bleu & or |
| 🍽 **Traiteur** | Catalogue au prix par personne, menu par événement calculé selon le nombre d'invités, **fiche de production cuisine** |
| 👗 **Inventaire & Location** | Chedda, karakou, burnous, costumes, trône, voiture de mariage, machine à fumée, sono… **anti-double-location par date**, cautions, alertes de retour |
| 👔 **Personnel** | Négafa, karkabou, zorna, chevaux, cortège de motos, DJ, photographe, organisateur… affectation par événement et planning du staff |
| 📈 **Rapports** | Encaissements sur 12 mois, taux d'occupation des salles, événements par type, **export Excel** |

## ⬇️ Installation

1. Téléchargez **`DZWedding-Setup-1.0.exe`** depuis la [dernière Release](../../releases/latest)
2. Double-cliquez — l'assistant est en français, **aucun droit administrateur nécessaire**
3. Le logiciel s'ouvre en grand écran, prêt à l'emploi

**Configuration requise** : Windows 10 ou 11 (64 bits). Aucune installation technique préalable.

### Premier démarrage

- Identifiant : **`admin`** — mot de passe : **`admin123`**
- ⚠️ **Changez ce mot de passe immédiatement** dans *Paramètres → Utilisateurs*
- Renseignez votre entreprise (nom, NIF, RC, AI, NIS, logo) dans *Paramètres → Entreprise* : ces informations apparaîtront sur tous vos contrats et reçus

## 🔑 Essai et activation

Le logiciel fonctionne **3 jours en version d'essai complète**, toutes fonctions débloquées.

Pour l'activer définitivement :

1. Ouvrez la page **Licence** (pastille en haut à droite de l'écran)
2. Copiez votre **identifiant machine** (format `DZW-XXXX-XXXX-…`)
3. Envoyez-le nous — nous vous renvoyons votre **code d'activation**
4. Collez le code, cliquez **Activer** : c'est définitif

> 💡 Votre licence est liée à votre matériel, pas à Windows : vous pouvez **reformater votre PC** sans perdre votre activation.

## 💾 Vos données

Tout est enregistré dans une base de données locale, dans le dossier d'installation.
**La mise à jour et la désinstallation ne suppriment jamais vos données.**

Pensez à utiliser régulièrement *Paramètres → Sauvegarde → Exporter* et à conserver le fichier sur une clé USB.
